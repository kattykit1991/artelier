# 🎨 Artelier

> Discover artworks from the Art Institute of Chicago, save your favorites, and create your own personal art gallery.

---

## ✨ About

**Artelier** is a web application for exploring and collecting art.

Users can search for artworks from the Art Institute of Chicago collection, discover new favorites, and save them to a personal gallery.

Saved artworks can be organized with personal notes, which can be edited whenever needed. The gallery is stored locally in the browser, so favorites remain available after refreshing the page.

Artelier is being developed as a learning project during my Software Engineering training at WBS CODING SCHOOL.

The project focuses on practicing React, TypeScript, API integration, and runtime data validation with Zod.

---

## 🛠️ Tech

**Current stack:**

- React
- TypeScript
- Vite

**Planned integrations:**

- Zod — Runtime data validation
- Art Institute of Chicago API — Artwork data
- localStorage — Browser-based gallery persistence

---

## 🚀 Run locally

### Prerequisites

- Node.js
- npm

### Installation

```bash
# Clone the repository
git clone <repository-url>

# Navigate to the project directory
cd artelier

# Install dependencies
npm install

# Start the development server
npm run dev
```

Open the local URL displayed in your terminal.
